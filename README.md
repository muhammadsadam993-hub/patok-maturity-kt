# Patok Maturity – KLK SWP Kebun Timur

Halaman info blok TBM PR23–PR26 Kebun Timur (PT Steelindo Wahana Perkasa · KLK Group).
Dibuka dari QR code di patok maturity lapangan, satu QR per blok:

`https://muhammadsadam993-hub.github.io/patok-maturity-kt/#blok-23a` … `#blok-26c`

Isi halaman: status fase hari ini (dihitung otomatis dari tanggal scan), hitung mundur bulan panen,
progress bulan ke-, lini masa maturing (tanam, mulai ablasi, CSI – Canopy Size Index drone,
stop ablasi, sanitasi pruning, NAA commercial, panen) dan data blok (Ha, clone, SPH, jumlah pokok).
